Publication outbox

Lock locally. Deliver later.

If Databricks had to answer on the RPD click, a warehouse outage would block approval. The outbox is a Postgres table: same transaction as the lock, worker delivers after.

RPD locksPolicy + authority. Operator is done.

Local lock is valid even while events sit queued

Writes stay off until DATABRICKS_ALLOW_WRITE=true, warehouse publication is on, and MERGE is signed off. Events sit queued. The local lock is still valid.
